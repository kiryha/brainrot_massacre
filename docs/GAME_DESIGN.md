# Game Design

## MVP loop

Join, approach one static character, press a temporary button, watch it break into physical pieces, then repeat after reset.

The breakup should feel exaggerated and playful. Interior surfaces may resemble foam, candy, crystals, glowing material, or mechanical parts; they must not resemble gore.

## MVP boundaries

The MVP has no weapons, damage, AI, animation, score, progression, monetization, or multiple characters. Those features remain deferred until the static fracture pipeline is approved.
