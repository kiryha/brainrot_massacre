# Product Vision

Brainrot Massacre is a small Roblox destruction sandbox built around artist-directed, stylized character breakup. The immediate product goal is not a full game: it is a reliable Houdini-to-Roblox destruction test that a child account can access.

Success means one original static character can be replaced by a matching pre-fractured model, physically burst apart, clean up, and respawn. `README.md` is the authoritative high-level definition.
